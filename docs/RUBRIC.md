# 답변 품질 루브릭

각 답변을 4개 항목으로 채점한다. 항목마다 0~2점, 합계 0~8점.

| 항목 | 0점 | 1점 | 2점 |
|---|---|---|---|
| **근거 일치** — 답변 내용이 검색된 근거 문서와 실제로 맞는가 | 근거와 다르거나 근거에 없는 내용을 지어냄 | 대체로 맞지만 일부 부정확·과장 | 근거 내용과 정확히 일치 |
| **인용 표시** — 어느 근거를 썼는지 [번호]로 밝혔는가 | 인용 없음 | 일부만 인용 | 핵심 주장마다 인용 |
| **거절 판단** — 근거가 없을 때 모른다고 하고, 근거가 있을 때 불필요하게 거절하지 않았는가 | 거절해야 하는데 답을 지어내거나, 답할 수 있는데 거절함 | 판단은 맞았지만 표현이 애매함 | 명확하게 맞는 판단 |
| **간결성** — 질문에 필요한 만큼만 간결하게 답했는가 | 장황하거나 핵심을 놓침 | 대체로 적절 | 간결하고 핵심적 |

**등급**: 7~8점 우수 / 5~6점 양호 / 3~4점 미흡 / 0~2점 실패.

이 루브릭은 사람이 답변을 읽고 직접 채점한다. 자동 판정(LLM-as-a-Judge, `근거성`/`거절 판단 적절성` 배지)은 이 중 "근거 일치"·"거절 판단"과 대응하지만 소형 모델(`qwen3.5:2b`)의 판정이라 신뢰도가 낮을 수 있다 — 실험에서는 사람 채점과 자동 판정을 나란히 적어 둘 어긋나는지 함께 본다.

## 실패 단계 분류

채점이 낮으면 원인을 아래 중 하나로 분류한다.

- **검색 실패** — 정답 근거가 top-K 안에 없었다(retrieval miss)
- **프롬프트 실패** — 정답 근거는 검색됐지만 프롬프트 조립·지시문 문제로 모델이 활용 못함
- **생성 실패** — 근거는 제대로 주어졌지만 모델이 잘못 답하거나 지어냄
- **판정 실패** — 답변 자체는 괜찮은데 자동 판정(LLM judge)이 틀리게 채점함
